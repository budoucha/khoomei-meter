# ホーミー倍音メーター

ホーミー（喉歌）の練習用に、マイクで声を取り込み、倍音が1本だけ浮いて鳴っているかをリアルタイムに表示するウェブページです。

**使う:** https://budoucha.github.io/khoomei-meter/

## 表示されるもの

- 判定（まだ出ていない／ちょっと出てる／出てる！）と突出度メーター
- ドローンの高さ、強い倍音の番号と音名
- 倍音番号つきのスペクトルと、倍音のメロディーが線で残るスペクトログラム
- マイクなしで見え方を確認できるデモ音

## しくみ

ドローンの基本周波数を YIN 法で推定し、550〜3200 Hz の各倍音について両隣2本ずつの平均より何 dB 大きいか（突出度）を計算します。普通の声では数 dB、ホーミーがうまく鳴ると 15 dB 以上になります。

マイクの音声はブラウザ内で処理するだけで、どこにも送信しません。
